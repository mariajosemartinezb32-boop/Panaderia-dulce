## 🛠️ Funcionalidades del Módulo Administrativo:
1. **✏️ Modificar Productos:** Actualizar nombres, precios en COP, fotos, descripciones y etiquetas destacadas de cualquier pan, torta, galleta o combo.
2. **➕ Agregar Nuevos Productos:** Registrar fácilmente nuevas delicias al menú de la panadería.
3. **🔄 Control de Disponibilidad:** Alternar entre `🟢 Disponible para la venta` y `🔴 Agotado temporalmente` con un solo clic.
4. **🗑️ Eliminar Productos:** Retirar productos que ya no se preparen en la panadería.
5. **💾 Persistencia Local:** Todo cambio se guarda automáticamente en el navegador mediante `localStorage` (sin base de datos externa ni servidor backend).
6. **📦 Copias de Seguridad:** Herramientas para **Exportar a JSON** y **Cargar/Importar JSON**.

## 🥐 Funcionalidades para Clientes:
- 🥖 **Catálogo Interactivo con Filtros:** Panes, Tortas & Postres, Galletas & Polvorones y Combos Especiales.
- 🛒 **Canasta de Compras:** Carrito dinámico lateral con cálculo de subtotales y domicilios en Tocaima.
- 💬 **Checkout Directo por WhatsApp:** Envío estructurado del pedido con productos, cantidades, dirección y método de pago a la panadería.
- 🎂 **Cotizador de Tortas en Vivo:** Personalización de porciones, bizcochos, rellenos y dedicatorias con presupuesto estimado al instante.
- 💼 **Cajero POS para Mostrador:** Módulo especial para que el personal de caja registre ventas rápidas, calcule vueltas e imprima tickets.
- 📍 **Ubicación en Tocaima, Cundinamarca:** Mapa interactivo de Google Maps integrado.

## 🚀 Despliegue en GitHub Pages:
1. Sube los archivos a tu repositorio de GitHub.
2. Ve a **Settings** > **Pages**.
3. En **Build and deployment**, selecciona la rama `main` (o `master`) y la carpeta `/ (root)`.
4. Guarda y listo: tu panadería estará disponible en línea.
